# Enterprise Multi-Site Network (CCNA Project)

## 📌 Overview
This project simulates a real-world enterprise network with multiple routers, switches, servers, and IoT devices.

## 🛠 Technologies Used
- OSPF Routing
- VLAN Segmentation
- DHCP / DNS / FTP / Email / Web Servers
- RADIUS (AAA)
- IoT Integration

## 🌐 Features
- Multi-site WAN connectivity
- Secure authentication
- Network services deployment
- End-to-end connectivity
